# 内阁、执政联盟与合作组织维护

2026-11-10核查：500席议会已于11月7日实装，当前候选维护以 [tools/parliament/README.md](../../tools/parliament/README.md) 及运行代码为准。下文六槽内阁包含保留的历史接口，不再表示议会尚未实施。

2026-11-10已改为[独立原生内容](../../tools/native_content.md)：候选及组织规则直接写脚本、文本和同步键，再由剧情登记/调用，不编辑JSON或中央分发表。候选任免、成员/首席效果、规则通过/替换、成员进退及组织解散均调用各内容自己的真实回调；组名、选项和队列/投票显示读取元数据。原ID和既有玩法保留；验证证据见[本轮记录](../../docs/tooling/20261110-native-content-api/README.md)。

## 现有内阁

主要入口：

- `interface/APDC_cabinet.gui/.gfx`；[common/scripted_guis/APDC_cabinet_scripted_gui.txt](<../../common/scripted_guis/APDC_cabinet_scripted_gui.txt>)。
- [common/scripted_effects/APDC_cabinet_scripted_effects.txt](<../../common/scripted_effects/APDC_cabinet_scripted_effects.txt>)；对应triggers和group_visibility_triggers。
- [common/scripted_localisation/APDC_cabinet_scripted_localisation.txt](<../../common/scripted_localisation/APDC_cabinet_scripted_localisation.txt>)、`APDC_cabinet_pie_scripted_localisation.txt`。
- `localisation/simp_chinese/APDC_cabinet*.yml`。

总理/副总理当前是国家变量 `APDC_prime_minister_character`、`APDC_deputy_prime_minister_character`保存人物token，头像/姓名经 `APDCPrimeMinisterPortrait/Name`等显示，不等于该人物已经成为原生 `country_leader`。少数总理有原生党首角色，另一些只有名字头像。后续要显示其意识形态时必须补数据，不能猜其所属。

内阁保留六槽，当前231条原生候选包括原真实人物、占位记录及其他国家人物。真实顾问效果通过相应ideas加减；“占位”不能当成正式人物造新加成。`APDC_update_cabinet_statistics`保留原六槽配额算法，并按原生候选元数据统计各党使用数、确保原生执政党在联盟；500席计算由议会选举脚本负责。新增候选要追踪slot选择、旧idea移除、新idea加入、所属类别、可用性、头像/本地化和刷新，不能只给GUI多画一个按钮。

更换大头像任务只改指定 `civilian.large`；不得顺带改 `small`、顾问或内阁共享头像。未来独立君主显示可以复用此“token→脚本本地化→GUI image”的成熟链，但不是已经完成的君主制。

## 执政联盟API

`APDC_governing_coalition_scripted_effects.txt`为九类主意识形态各提供：

```text
GER = {
    APDC_add_socialism_to_governing_coalition = yes
    # 可用相应 remove_<主类>，但不能移除当前原生执政党
}
```

`APDC_clear_governing_coalition`清伙伴并保留当前执政党；退出联盟同步清理对应内阁成员。`on_ruling_party_change`等入口与缓存联动，不要只改旗标。当前一个主意识形态对应党名，不是已经支持同一主类下无限多个独立议会政党的完整模型。

## 合作组织容器

组织独立于军事阵营。一个国家当前最多加入一个组织。组织以锚点国家scope存储成员、主席、法案、投票、队列；成员只持有 `APDC_cooperation_organization_container`指向锚点，并镜像显示数据。**锚点不必与永远的主席相同；不要把换主席写成新建另一个容器。**

入口：`APDC_cooperation_organizations_scripted_effects.txt`、`APDC_cooperation_legislation_scripted_effects.txt`、`APDC_cooperation_organization_templates_scripted_effects.txt`，同名前缀GUI、triggers、localisation、on_actions。

### 新建组织模板

1. 复制 `APDC_create_fifth_international_cooperation_organization_from_template`或国际罗克萨特主义模板，选唯一definition/name/icon ID。
2. 在 `APDCCooperationOrganizationName/Icon`脚本本地化和GFX登记名字、图标。
3. 在锚点scope设置三个ID，调用 `APDC_create_cooperation_organization`。
4. 模板明确列开局成员，调用 `APDC_apply_cooperation_organization_template_opening_members`；选已加入成员任主席。
5. 默认占位法案会随容器初始化；自定义法案组通过统一API注册，不复制一套组织专属后端。

```text
SOV = {
    set_variable = { APDC_cooperation_organization_definition_id = 3 }
    set_variable = { APDC_cooperation_organization_name_id = 3 }
    set_variable = { APDC_cooperation_organization_icon_id = 3 }
    APDC_create_cooperation_organization = yes
}
GER = {
    set_variable = { APDC_cooperation_organization_join_target = SOV }
    APDC_join_cooperation_organization = yes
    # 退出：APDC_leave_cooperation_organization = yes
}
SOV = { APDC_set_cooperation_organization_chair = yes }
```

示例ID3仅为文档示例，使用前扫描现有注册，不能直接假定未用。容器解散在锚点调用 `APDC_remove_cooperation_organization`，用统一清理链处理成员和法案。

## 法案扩展

按 [原生规则模板](../../tools/templates/native_organization_rule.txt.example) 填写定义及真实回调，在组织锚点scope调用本内容的命名登记包装：

```text
SOV = { APDC_example_rule_register = yes }
GER = { GER_example_rule_propose_option_2 = yes }
```

底层完整登记入口为 `apdc_register_organization_rule`，参数 `apdc_nr_id`；成员剧情提案为 `apdc_propose_organization_rule`，参数 `apdc_nr_id/apdc_nr_option`。正常投票、队列、休会和成员视图共用原算法。`setup` 只填写元数据与纯条件；当前5分类、每组1至4项，规则组数不锁定为40。

`_on_enact/_on_repeal` 在锚点运行；`_on_member_apply/_on_member_remove` 在成员运行；`_on_fail` 处理失败提案。首次登记实施默认项一次；通过时先撤旧效果再施新效果；进退组织及解散均对称清理。原40组占位定义保持空效果，不擅自发明正式奖励。

重复登记不重置已选项、锁和队列。条件每天刷新；原 `APDC_change_cooperation_law_option_availability_in_container` 仍可显式覆盖选项可用性。原始 `APDC_register_cooperation_law_group_container` 是内部/旧兼容接口，不能代替完整原生内容登记。

## 输入与显示维护

组织五标签分页及外交成员侧栏是其他自定义面板的参考实现。国家旗帜在前景，不能因缓存优化偏移。投票区整个空白可点击已接入；三块投票列表只隐藏滚动条视觉，保留真实控制器与滚轮，不删除scrollbar声明。静态/加载已通过，真实鼠标操作仍待验。

正式增加组织前确定名称、主席和成员。国家资料中的“民主国家联合体”尚未确认能否等同“民主国家共同体”，“咕咕农场”也未定义，不擅自合并或新建。
