## 页面与玩法

世界地图轮廓来自当前 [map/provinces.bmp](<../../map/provinces.bmp>)、`definition.csv`和州地块归属，颜色/国家边界读取运行中的**拥有国**，不是临时控制者。国家领土易主可更新，固定地理纹理不写死tag。

- 本国红填充、不可干涉灰、可干涉蓝、剧情已控制粉红。是否可干涉/已控制均为按施行国—目标国独立剧情状态，不按控制份额自动推断。
- 世界图ZZZ无人区纯黑，对其他国家的国界红色；仅此冷战世界图，不能改国家RGB、主地图或详情图。
- 可干涉国家悬浮黄国名，点击详情；整国亮蓝悬浮仍未实现，当前禁用整国/单州亮暗效果。
- 详情只取目标国**当前拥有且为其核心的州**，左侧等比居中，不含非核心属地。跨经线使用两种原点选紧凑包围盒；无核心领土显示空图，不生成NaN缩放。
- 详情填当前国家地图色，粗蓝白国界、细蓝白州界。主地图修改地块后必须同步这里的地理输出。
- 右半：完整国名、意识形态、经济体制、军事阵营、合作组织、国际地位、政治/经济/军事亲谁；无某项组织则“无”。
- 份额超过50%才显示亲该国，否则自主；不要将恰好50%写成亲某国。
- 国际地位1未获承认、2附属国、3弱国、4小国、5地区性大国、6国际性大国。基础是剧情设定；原生附属关系覆盖为附属国，不抹掉保存的独立国际地位。

下方三标签为政治/经济/军事控制。大地图时展示我方自身；详情时展示目标国。左边实心饼图+图例，只有有份额的国家及自主，自主用该国颜色。悬浮黄简称、白色两位小数份额，并显示增长/降低及来源，正绿负红。

## 控制算法

每条轴合计100%，自主为来源索引0。一方份额变化时其余来源按比例补齐；一般情形其它份额乘 `(100-新份额)/(100-旧份额)`。0/100退化边界、来源登记和清理使用现成接口，不在剧情里自行算数组。

若国家A对B的政治份额低于 `(经济份额+军事份额)/2`，政治向目标上升：差距每1个百分点对应每日0.01个百分点，通常最低0.01、最高0.1，最后一步不越目标。高于目标不会自动回落，但别国份额增加仍会使它按比例下降。法案停止只停持续效果，不撤销历史份额；国家不存在时按停止处理。

只有已登记关系/法案每日结算；不每日重扫全世界图形。干涉/已控制标记与份额互相独立，改变份额不能顺便自动开干涉或设附属关系。

## 可直接复用的剧情接口

以下为**现有真实接口**，不是尚未制作的议会/君主制伪代码。参数先放国家变量，注意scope。

### 可干涉/已控制：在施行国作用域

```text
GER = {
    set_variable = { apdc_cw_target = FRA }
    set_variable = { apdc_cw_value = 1 } # 1添加，0取消
    apdc_cw_set_intervention = yes
    # 如剧情另行需要已控制状态，再调用：
    # apdc_cw_set_controlled = yes
}
```

### 份额：在目标国作用域

```text
FRA = {
    set_variable = { apdc_cw_actor = GER }
    set_variable = { apdc_cw_axis = 2 } # 1政治、2经济、3军事
    set_variable = { apdc_cw_delta = 5 } # 百分点，可负
    apdc_cw_change_control = yes
}
```

提高自主时actor用目标国本身。避免全局事件目标承载“玩家当前选择”，每个玩家/国家独立保存显示选择。

### 国际地位：在目标国作用域

```text
FRA = {
    set_variable = { apdc_cw_value = 5 }
    apdc_cw_set_status = yes
}
```

### 法案

复制[原生行动模板](../../tools/templates/native_cold_war_action.txt.example)为独立脚本，填写永久ID、目标/受益国、轴、日变化、费用、名称/说明、条件及回调，维护正常本地化和同步键。在施行国调用本内容的命名解锁包装；第一次默认停止，重复解锁不重置执行状态。剧情直接执行/停止也有命名包装，仍受可用性和费用约束。原28条 `apdc_cw_unlock_law_<ID>` 保留兼容。

```text
GER = {
    set_variable = { apdc_cw_target = FRA }
    set_variable = { apdc_cw_id = 1 }
    set_variable = { apdc_cw_value = 1 } # 0解锁可选性，1锁定
    apdc_cw_lock_law = yes
    # 需要停止并从列表移除时调用 apdc_cw_remove_law = yes
}
```

锁定仅改变可选性；不要未经确认把它改成清除历史效果。执行与停止切换共用同一 `cost`，存档数组沿用旧 `execute_cost`名称，不能据名字误恢复两套收费。

## 性能与质量保护

`render_mode.json`必须保持用户选定的 `native`。原生世界图按钮/坐标/图层/贴图不换成运行后替图或懒加载列表；这些曾产生边缘混合变化或首次打开约19秒等待。当前方案接受启动资源初始化约50—60秒，打开/返回尽量复用缓存；不是承诺所有机器固定该秒数。

图形有26档缩放、原生完整距离场和调色板。`steps`编码倍率须与shader解码一起改变，否则地图错误色。饼图保留360扇区，提示缓存采用数组，不能为每法案展开360份字符串。变量/循环计数器统一小写，避免引擎不同路径大小写处理导致索引归零。

**重要显示回归**：地图数据缓存有效≠隐藏GUI绑定已经刷新。首次打开、关闭重开、详情返回、加载都要调用 `apdc_cw_bind_world_ui`推进GUI版本；数据构建计数与GUI更新计数分开。验收先做“没有任何领土/控制变化的普通开局首次打开”，再做会使数据dirty的综合测试，否则会掩盖全图红色/州界全露的初始化错误。

改地图后保护非地理文件：入口、按钮、饼图、法案、背景、国际地位、当前权限接口均不应被重置。`check_ui.py`检查实际热区和几何；`qa.py/qa_visibility.py/qa_world_style.py`有独立场景，先检查其旧profile路径和预设，再选用。
