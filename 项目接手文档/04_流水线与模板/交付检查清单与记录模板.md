# 交付检查清单与记录模板

## 修改前

- [ ] 根AGENTS与本专题最新状态已读，用户本轮授权范围明确。
- [ ] 定义、API、UI、生命周期、验证五层已定位。
- [ ] 本轮现场备份和哈希已存项目外，已有未提交工作保留。
- [ ] 生成器的桌面输入、稳定ID、固定日期备份、删除动作与副作用已检查。

## 修改后

- [ ] 仅改本轮目标；没有顺带覆盖国家、人物、地图、顾问或美术。
- [ ] 无无效key/引用、重复ID、错误BOM和本地化覆盖。
- [ ] 真实工厂可用数、库存、角色归属、核心等不能只用显示变量验证。
- [ ] 缓存未脏时首次打开也正确；保存重载/状态切换不串数据。
- [ ] 条件边界（0/负数/上限/缺项/国家消失/战争/禁运）覆盖本轮相关部分。
- [ ] 按任务实际需要做静态、运行、视觉/鼠标验证，三类分开写。
- [ ] 所有本次自建游戏/助手进程退出；用户正常文件不被回滚或覆盖。
- [ ] 只保留必要证据；不持续堆D盘根目录完整QA工程。
- [ ] 更新当前状态、专题维护来源、验证边界与工具输入。

## 单轮实施记录模板

```markdown
# 日期—主题

## 用户要求与范围
原始要求；明确排除项；对旧设计的覆盖更正。

## 当前最终行为
用具体触发和前后例子说明，区别实现与建议。

## 文件与维护来源
输入数据/素材；生成器；运行输出；API与scope；稳定ID/迁移。

## 保护与备份
本轮备份位置与哈希；哪些既有内容保持；不要以旧备份否定合法新值。

## 验证
- 静态：解析/引用/像素/哈希。
- 运行：版本、启用mod/DLC、PID、实际日期/存档/断言。
- 视觉/输入：实际检查了什么，截图来自哪里，未检查什么。
- 失败诊断和最终复验分别记录。
- 自建进程清理及用户文件保护。

## 遗留与下一步
用户未定值；未找到的接口；尚未完成的画面/交互验证；可直接继续的入口。
```

## 新增法案/人物/组织记录模板

| 字段 | 内容 |
|---|---|
| 稳定ID及所属系统 | 不随排序改变；是否占用旧ID |
| 正式名称、说明、语言 | 作者署名是否应剔除；空值规则 |
| 施行者/目标/人物/组织锚点 | 明确scope和身份 |
| 解锁与可用条件 | 含科技、政体、战争/禁运、点数等已确认项 |
| 一次性/持续效果 | 切换费用、停止是否保留历史效果 |
| 生命周期 | 取消/移除/国亡/保存重载/更新迁移 |
| 来源与输出 | 哪个JSON/生成器/脚本/图像是权威输入 |
| 验证与边界 | 不用“零报错”替代功能证明 |
