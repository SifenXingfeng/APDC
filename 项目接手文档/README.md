## 如何解释本目录中的状态

- **已实现**：有当前运行文件或明确完成记录；不等于所有交互和后期剧情都测过。
- **静态验证**：语法、引用、文件或像素检查；不能替代真实战局、点击与画面。
- **运行验证**：后台真实开局、日期、断言或存档；不自动代表视觉通过。
- **待视觉/交互验收**：没有足够的真实画面或鼠标输入证据，必须如实保留。
- **已确定、未实现**：设计已经讨论，不能把建议的变量、接口或流程当作已有代码。
- **待定**：用户没有给出最终规则，或原文存在边界不一致；不得自行写成正式设计。
- **历史记录**：记录当时事实。后来的合法修改、最新检查点与用户更正优先。

## 防止接手误判

1. 500席议会已于2026-11-07实装并完成后台、存档重载和主要画面验证；君主立宪制元首展示分离仍未实装。不要用旧内阁支持率或规划接口覆盖新运行规则。
2. 原版战略资源贸易与国际市场最后决定保留；已做的是独立消费品市场及私营装备采购。
3. 国王的姓名头像不能全局劫持原生 `GetLeader`：自定义展示与真实执政者要分开。
4. 2026-10-28 临海国界误判已经改代码并通过后台开局，但指定沿海近景前后对照未完成。
5. “默认/空白/没有新头像”绝不等于删除原固定党首或清空其旧头像。
6. 不得为清日志再次误删抵抗、外交、情报、自动师名、可选企业和项目的引擎入口。
7. 当前大量已完成改动尚未提交；不要 reset、clean 或从旧生成器覆盖现场。
