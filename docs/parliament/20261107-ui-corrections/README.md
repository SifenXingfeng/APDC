# 2026-11-07 议会界面九项修正

本轮按用户实际反馈修正上一版界面，替代此前相应的布局和输入配置。经济系统选择器和旧内阁饼图作为直接来源，不再另做近似版本。

| 反馈 | 已修改的实现 |
|---|---|
| 主面板不能拖动 | 将原先鼠标穿透的背景图标恢复为原生窗口背景，保留 `moveable=yes`、置前行为，并关闭背景的透明像素命中检查 |
| 法案选择器与经济系统不同 | 直接读取经济系统的原始选项行和侧栏，复制构图、坐标、字体、图标按钮、费用、对齐、滚条和300ms滑出参数；只替换议会数据与名称。悬浮窗沿用“名称/效果＋更换花费＋限制说明”结构 |
| 日期格式不符 | 改为“2062年1月1日”形式，继续使用原生日历生成的下次选举日期 |
| 按钮命中异常、点击穿透 | 候选姓名/特质/费用等文字不再截获鼠标；卡片本地精灵保留原图并关闭透明像素命中；图标和整行共用提案处理；列表恢复同一父窗口的原生上下文，弹层使用真实背景承接空白处输入 |
| 解除任命无效且位置/底图不符 | 恢复到候选副面板的直接事件上下文，置于底部中央，使用67×24谈判/封禁按钮底图；只有所选岗位有人时才可用。后台已验证职位和成员加成同时撤除 |
| 多余“内阁成员”标题 | 删除左上角岗位标题控件；保留党派分组及名额信息 |
| 饼图外圈错位 | 原样读取旧饼图片段与滤镜圈，只整体平移；恢复旧滤镜圈1.42缩放，与0.112饼图容器配套 |
| 九党名称前缺少颜色方框 | 九行均加入旧内阁同源的颜色图例，保留当前九类意识形态与既有色板对应 |
| 政治页入口偏移 | 按背景原图建立y=44锚点。半圆中心为原图(116,511)，讲台在原图(98,489)，位于半圆中间空位；当前素材实际36×38，点击框直接读取图片尺寸 |

## 直接证据

- [主面板](runtime/main.png)：中文日期、饼图外圈、九党图例。
- [已任命的内阁副面板](runtime/cabinet_appointed.png)与[解除后的副面板](runtime/cabinet_dismissed.png)：底部居中按钮、所选岗位回空、按钮灰化、无额外岗位标题。
- [法案选择器](runtime/law_side.png)：经济系统同源构图、原尺寸图标、名称和费用位置。
- [入口对位预览](runtime/entry_preview.png)：在游戏中用实际政治页背景、原总理/副总理组件和实际入口组件组合核对。此图是QA组合窗口，不是通过鼠标打开原生政治页的记录。

19项界面专项检查包含经济选择器的结构对比、旧饼图缩放、文字输入透明性、按钮绑定、九党图例、中文日期、入口锚点和素材/点击框尺寸；原29项静态与数值检查继续通过。实际游戏回归确认任命后加成存在、解除后岗位与加成都清除，并取得1920×1080各状态画面。运行日志和最终检查点在本目录中保留。

真人鼠标拖拽、悬浮、逐点命中和滚轮未在用户桌面上执行。一次针对自有隐藏窗口的消息测试没有触发引擎鼠标操作，不作为通过证据；不能把配置或后台API测试说成真实鼠标点验。测试始终没有切换输入桌面，也没有注入系统鼠标/键盘输入。

本轮只涉及议会界面、命中配置和日期显示辅助变量；选举、法案、经济规则和国家历史没有改写。原始文件与失败诊断位于 [backup.json](backup.json) 指向的项目外备份。
