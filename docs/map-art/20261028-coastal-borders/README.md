# 临海陆上国界颜色回退修正

## 原因与修改

`border.shader` 原先要求 `vGFIsInland > 0.5` 才对国家边界应用现有蓝白色。这个值读取的是边界图集中的粗陆海遮罩，使用 4×4 地图像素一格的二值数据。海岸附近有额外的向内排除带，导致仍属于陆地的国界末端切回原版着色流程。颜色分支没有以海拔或坡度作条件；原版顶点水面高度钳制仅影响几何位置。

当前图形数据中，13,125 个完全属于陆地的 4×4 格被旧遮罩排除；35,548 个实际开局陆上国界采样点中，1,673 个被排除，其高度图值覆盖 89—173。因此不能把该现象归为固定海拔阈值。

游戏数据仅修改 `gfx/FX/border.shader`：删除国家边界白色着色条件中的 `vGFIsInland` 检查。国家边界类型识别及选择覆盖检查继续保留，白色亮度、线宽、透明度、发光和原版非国家边界流程均未改。陆海图集、高度图、地块图、国家颜色、光照、水面与游戏玩法未修改。原始字节与校验记录保存在项目外备份中。

## 验证与边界

最终主项目后台普通 GER 2060 开局成功，实际推进至 2060 年 3 月 3 日，并取得 3 月 1 日文本自动存档。相关着色器编译错误为零；测试加载主项目真实着色器，没有私有着色器覆盖。最后测试进程与匹配的辅助进程均已退出，Steam 运行状态已恢复。用户正常配置、继续游戏信息和自动存档的受保护哈希一致。14 项其他地图/美术数据哈希保持原值。

**沿海国界末端的完整画面对照尚未完成。** 私有后台截图未能将视角准确定位到法低沿海交界，不能把这些截图当成该位置已经视觉验收。定点镜头测试中有一次纹理加载期间异常退出，其日志与异常报告已保留，尚不能确定根因；随后采用稍远视角加载同一最终项目着色器，开局和日期推进通过。未为通过测试删除主项目功能或降低边界贴图质量。

备份与各次测试详情见 `verification.json`。不据此承诺全图所有缩放与临海细节已经逐一视觉确认。
