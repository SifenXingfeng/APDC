## 确定的代码事实

1. GF-MAP 与 APDC 的六个地图着色器完全相同，移入的光照/边界参数也相同。不能仅因原 APDC 曾注释 `dominance_fx_apply` 就认定重新启用这一函数是根因。
2. GF-MAP 没有覆盖 `common/terrain/00_terrain.txt`，实际使用当前游戏的定义。APDC 覆盖了这一文件，保留了较旧的海洋定义。
3. 当前游戏的 `ocean` 有 `naval_terrain = yes`，APDC 缺少；当前游戏四类基础海洋都有正数 `minimum_seazone_dominance`，APDC 四类均未定义。
4. `pdxwater.shader` 第 352 行调用普通海区渐变，第 405 行调用海军优势显示。后者依赖运行时的海区控制遮罩，因此相同着色器文件不能保证不同地形配置下的显示输入一致。
5. 此次普通开局存档与 GF 最近维护存档的战略海区 `dominance.countries` 均为空；没有证据表明 APDC 实际开局存在全球海军控制。

| ocean | 250 | naval_terrain = yes |
| water_fjords | 100 | — |
| water_shallow_sea | 100 | — |

阈值取自当前安装的基础游戏定义，与 GF-MAP 实际采用的定义一致。未移入整份原版地形文件；APDC 的地形战斗宽度、攻击、移动、补给和其他既有字段经过逐项语义对照，全部保留。未修改任何着色器，海军优势显示仍启用。APDC 独有、当前海区未使用的南方海洋类别也保留。
