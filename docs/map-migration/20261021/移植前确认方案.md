# GF-MAP → APDC 已确认移植方案（尚未实施）

用户已确认所有313个来源身份的处理方式。本轮仅更新方案、映射和影响预计算；APDC与GF-MAP的实际注册、州文件、核心宣称和其他游戏内容均未改写。

## 已确认的实现边界

- 完整采用GF-MAP地图底层、州划分、地理环境、人口资源、现代城市胜利点、补给铁路、模型位置、美术字体及地理本地化；兼容主项目自定义建筑、单位与脚本。
- 国家身份采用APDC。保留主项目国名、颜色、旗帜、人物、政党意识形态、经济制度、国策、科技装备、外交阵营附属及其他玩法；只按确认映射转换地理关系，不整份覆盖国家历史。
- 保留2060开局。首都与州/地块引用按新地图位置适配；GF旧日期分支不能在2060开局重新覆盖既定地图数值或政治数据。
- 28个已有主项目国家历史但缺注册的身份：用户确认补齐注册，沿用现成主项目设定。39个缺少主项目身份的国家：用户确认补建。即使清理后某国没有领土或剩余核心，也不撤销已经确认的注册/补建计划。

## 新增核心与宣称清理规则

1. 先完成全部tag对应、合并、南苏丹拆分和关系去重，再统计各目标国家在全图的开局自有领土。
2. 若一个州已经属于其所有者的核心地区，删除该州所有“全图开局自有领土为零的tag”的核心和宣称。
3. 若州所有者不是该州核心，不触发此清理；不能借此给所有者补核心。
4. 对全图任何地方拥有开局领土的tag，其核心和宣称均保留，哪怕不属于该州所有者。
5. 此规则只整理开局地理关系，不删除国家定义、人物、国策或未来正常创建/释放该国的功能，不添加持续锁定脚本。

## 当前来源关系的预计算

- 映射后：1558州、156个拥有开局自有领土的目标tag。
- 所有者已经拥有本州核心：1490州；另外68州不触发清理。
- 按规则将影响391州，删除445项核心关系和11项宣称关系。
- 数量基于GF当前关系完成tag转换后的预计算，并非已经写入游戏。主项目原有宣称若在正式移植时适配保留，也必须在最终开局数据上执行同一条清理规则。
- 7个已授权补建的国家在清理后没有任何开局领土/核心/宣称；它们仍列入补建计划。
