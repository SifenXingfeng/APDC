# 消费品贸易：卖方选择买方

按用户 2026-10-24 的要求，把卖方对多个买方的等额分配改成逐家满足。买方仍然优先选择关税低的卖方，同税率下优先选择出口量大的卖方；卖方则优先选择关税低的买方，同税率下优先选择本轮贸易前消费品绝对缺口大的买方。

这里的缺口是需求减去未计本轮贸易的分配后供给，包含现有额外输入/输出和分配率，不按缺口百分比排序，也不把贸易法案允许的进口额度误当成完整缺口。一次交易的数量是卖方剩余出口量与买方剩余进口额度中的较小者；前一家进口额度满足后才分配给下一家，供货用完即不再成交。进口额度仍沿用经济系统原有计算结果。

## 实现

- `tools/economy/build_market.py` 及其生成的市场效果、国家评分器实现此规则。关税分组后再按缺口降序排序，避免把两项条件混成可相互抵消的加权分数。对一个固定卖方，其自身出口税对所有买方相同，因此买方进口税的顺序等同于双边合计税率的顺序。
- 每周撮合开始时生成一次买方名单，所有卖方复用。逐个卖方撮合时不再重新排序，也不重新全图搜寻买方；继续按既有七批处理并整份发布新安排。
- 本轮初始缺口固定到安排完成，已成交进口不反复改写排序。每笔交易扣减剩余进口与出口额度，后面的卖方不会重复填满已经满足的买方。
- 保留双向禁运、交战和不存在国家的排除。每日既有关系缩减、关税、消费品分配、贸易列表生成、经济后端和界面保持原有逻辑。
- 新增一次性的 `APDC_eco_market_priority_v1` 标记。旧存档若缺少此标记，保留当前已发布安排，取消旧的未完成撮合并请求分批重建；不沿用旧实现按单个卖方生成的临时买方名单。
- 同步调整 `tools/performance/weekly_economy_qa.py` 中依赖等额分配的旧测试数据和断言；新增的 `tools/economy/market_priority_qa.py` 使用真实项目效果与原生国家评分器验证。
