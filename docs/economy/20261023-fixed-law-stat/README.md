# 经济法案固定人口消费品系数

> 后续收到实际画面截断反馈，已将数值栏加宽为 58 并明确关闭省略号；同时修正了发展度列表的显示条件，详见 `../20261023-law-list-visibility/README.md`。本文保留当时的 32 像素布局记录。

按用户要求，使用各法案独立的固定文本：民用经济 1.00、前期动员 0.85、部分动员 0.70、战时经济 0.55、总动员 0.40；两档隔离政策为 1.00。均为黄色两位小数，无加号。其余六个既有经济法案按后端实际默认基础系数显示 1.00，没有修改其人口系数修正。

## 实现

原生 `political_selectable_idea_entry_list` 已有由引擎逐条填充的 `traits` 文字栏。当前其他列表法案不使用可见的特质名称：科研、社会及国防三种标记在中、英本地化中均为空。复用此文字栏，每条经济法案附加一个只有名称、`random=no`、不带任何 modifier 的显示特质。

将该栏移到行内 x=400、y=32，宽 32、高 20；父容器允许溢出绘制，控件继续 `alwaystransparent=yes`，原生名称、费用和按钮不变。原 `stats` 的消费品段保留原图标，将原生数字换成 24×20 的透明占位图标；煤炭段不改。独立文字补入固定数值，不读取当前国家或已生效法案变量。

`tools/economy/build_law_stat_display.py` 负责生成；`build_data.py` 已接入，重复生成无变化。所有经济法案的 modifier 块、整个经济后端和工厂占用动态修正均与本轮备份相同。没有恢复原生消费品系数，也没有新增经济计算。
