## 计算与性能边界

结算公式、贸易撮合、工厂占用及装备生产均未修改。正式后台脚本相对备份只增加一条赋值：在计算分配率之前记录本次实际读取的 `last_civ_capacity`。随后的缺口计算会更新该变量，因此直接在提示中读取最新值会与已经算出的分配率不一致；新增的 `distribution_capacity_input` 仅供显示，不参与计算。

其他新增显示数值都在既有 `sync_ui` 中读取或计算。日常刷新仍仅对已打开面板的玩家执行，没有新增全世界扫描、贸易匹配或州统计。经济动员法案、隐藏工厂占用修正、贸易脚本、on_actions 和政治界面文件的字节均与备份一致。

维护入口为 `tools/economy/presentation.py`、`build_ui.py`；同时同步了 `build_data.py` 的说明和可用条件，以及 `build_backend.py` 的显示快照，避免下次生成丢失。
