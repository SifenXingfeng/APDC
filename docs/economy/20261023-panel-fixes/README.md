# 经济面板与法案修正（2026-10-23）

> 后续发现本轮人口系数展示改动造成国营民工无法分配；原“抵消检查”只检查聚合修正，没有检查实际可用工厂，不能证明此项正常。相关改动已经撤回，原因、恢复与最终验证见 `../20261023-panel-regressions/README.md`。本文保留当时记录，不作为上述回归修复后的最终状态。

本轮按用户列出的界面问题修改，游戏数据、生成器和新增资源共 20 个文件，前后哈希见 `changes.json`。没有重建经济后端；生产、建设、贸易、预算及每周结算函数保持原字节，80 档发展度和法案的 modifier 块也保持原数值。

## 已修改

1. 三个政治发展度类别补齐原版的 `law = yes`、`use_list_view = yes`，采用原先复制的法案图标和对应类别特质；五个等级在原版法案列表中展示，费用统一 -1，等级仍由经济系统自动更新。
2. 经济动员法案的人口消费品基础系数通过带黄色定值名称的特质提供，显示 1.00、0.85、0.70、0.55、0.40，取消自定义修正自动生成的正号。原消费品统计图标不变，统计文字格式改成黄色两位小数。特质中的原生期望值使用同一个系数，隐藏分配修正继续将自动消费品占用抵消为零；七档（含两个隔离法案）均作实际引擎系数与抵消检查。
3. 用于扣除国营消费品民工、抵消原版期望值的动态民族精神移除可见图标，按本体已有隐藏动态修正的方式处理。
4. 温饱、教育、医疗共 15 个阶段图标取消 0.45 倍缩放，删除叠加的等级数字控件。
5. 法案侧栏改成独立 scripted GUI，挂在经济面板的专用 hook；hook 位于不透明主面板之前，使侧栏从主面板后向右滑出。使用与外交合作组织侧栏相同的显示/隐藏动画声明，动画时间 300 ms。打开经济面板时清除旧选择，选定法案或手动关闭时收起。
6. 卢布使用独立的白色、黑描边字形图片及内联文本图标，替代字库缺失的 Unicode 字符。字形预览为 `ruble-preview.png`。
7. 所有经济界面的 `vic_18_black` 小字改为白色描边的 `hoi_18mbs`；保持已有白色标题字体。
8. 国营民工名称和数量分开，减号、数量、加号置于同一行，两个按钮在数量两侧。
9. 贸易消费品名称和净贸易数字合并为同一个居中文本块。
10. 展开按钮按用户素材的两帧定义，单帧宽度 42 像素；收起使用第 1 帧，展开使用第 2 帧。
11. 贸易国背景、列表和滚动条由单独的菜单 GUI 控制整体显隐，折叠时不保留滚动条。
12. 贸易方向指示条改至 x=331、y=575，单帧中心与总消费品框中心对齐，放在贸易框与总消费品框之间。
13. 分配率框使用独立本地化键，避免被底部“分配控制”法案的同名键覆盖；显示“分配率”及具体百分比。
14. 供给与需求各自拆为标题、数值两个控件，在框的上、下半部分分别居中。
15. 两条私营建设进度条上移 1 像素至 y=876。
16. 私营工厂数量改用 `_raw` 的真实建筑座数，显示整数。之前显示的是有效工厂数：未受损建筑等级乘以 `max(0, 1 + local_factories)`，因此会出现小数。有效工厂数继续参与原产出和建设公式，没有把产能强行取整。
17. 购买弹窗挂在经济主面板最后面的专用 hook，以保持在主内容上层。原 `GFX_standard_button_88` 是文本精灵，现用同一原版纹理建立普通按钮需要的可伸缩贴图声明，明确加减、最大和购买按钮尺寸。没有更换采购结算公式。
18. 购买弹窗装备名称上移至 y=83；加减按钮、最大、总价下移，购买数量下预留了一行空间。未加入不可读写数量的装饰性滑条。

## 暂未实施的两项

- **建设页计入生活消费品栏**：现有 `civilian_factory_use` 将这些工厂计入原版国家项目。未找到能够单独指定原版生活消费品一栏数量、同时保持当前可用工厂扣除和计算口径的可靠接口。本轮保留当前分类和扣除方式，没有通过改标签或增加原生消费品占用来伪装分类。
- **拖动滑条设置采购数量**：本体提供横向 scrollbar 控件，但当前项目和 TNO 示例及 scripted GUI 接口核对中，没有找到把拖动值可靠读回采购变量的绑定方式。保留预留行和已修复的加减、最大按钮，未放入不能实际改数量的滑条。[所核对的 scripted GUI 属性/回调定义](https://github.com/cwtools/cwtools-hoi4-config/blob/master/Config/common/scripted_guis.cwt)只作为接口排查依据；这里记录“尚未找到实现路径”，不将其推断为引擎永远无法实现。
