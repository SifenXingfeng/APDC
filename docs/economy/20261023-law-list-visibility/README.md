# 系数省略号与发展度列表修正

本轮只处理用户反馈的两项：固定系数仍被省略号截断，以及三个发展度列表只显示当前一档。

## 修正

- 系数原文字栏宽 32 像素且使用默认截断。现加宽至 58，并明确设置 `truncate = no`；横向位置仍为 x=400，右端 x=458，不超出 462 像素的原版列表行。同步修改生成器。
- 十五档政治发展度此前同时设置 `allowed=no`、`available=no`。前者将非当前条目从原版列表排除，造成只剩当前一档。现对这十五档改为 `allowed=yes`，保留 `available=no`、费用 -1、`cancel_if_invalid=no`。因此五档可列出而不可手动选择，等级继续由经济系统决定。其余隐藏法案和旧版残余发展度不变。
- 经济法案所有 modifier、十五档发展度及其他隐藏法案的全部 modifier、经济后端与分配动态修正均保持原样。
- 现有经济面板 QA 增加“每组至少五档可列出”的引擎条件，与原有的不可选择检查同时保留，避免再把“全部隐藏”误判为正确锁定。
