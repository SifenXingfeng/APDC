# 货币与消费品统一计量单位

按照用户确认的规则，货币与消费品在每 1000 倍切换一档：原数值、K、M、B、T、Qa、Qi、Sx、Sp、Oc、No、Dc。保留两位小数，负数按绝对值选择单位；零显示 0.00，来源提示的零贡献仍整行隐藏。

统一覆盖国库、每周收支、总消费品、供给、需求、额外输入/输出、消费品净贸易、贸易伙伴列表、采购总价以及对应的直接来源提示。工厂数量、装备数量、等级、百分比和时间的已有精度与单位不变。来源提示仍然只有直接增减，没有公式或中间值。

## 实现边界

`tools/economy/number_format.py` 提供共享格式；`build_ui.py` 生成显示缓存和本地化，`direct_sources.py` 复用相同缓存。格式只在既有 UI 更新中计算，未增加世界贸易撮合、国家/州扫描或 AI 计算。贸易伙伴只遍历已经生成的本国展示列表。

国库与采购金额继续使用原有的 M/K 两部分结算。接近零时先在 K 中组合，保留卢布小数及小额负余额；显示更大的单位时才缩放，实际余额、价格及支付数据均不改变。采购数量按钮只更新金额显示缓存，避免为改数量重跑整套面板统计。

实测直接使用原生大数除法会溢出，格式器对大数采用小倍率分步缩放，再提升对应单位档位。测试输入 Qi 量级时用安全加法构造，避开脚本整数常量读取和乘法中间值的限制。不要改回直接除以 1000 的旧实现。
