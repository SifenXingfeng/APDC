# 来源提示只显示直接贡献

本轮按用户补充要求，覆盖上一轮来源提示的展示方式：只显示“来源：增加/减少多少数值或百分比”，所有零贡献整行隐藏。保留黄色标题、空行、基础黄色、增加绿色、减少红色及卢布图片图标。

- 国库周变化只列各项税收及开支对国库的实际增减；支出转换为负贡献，负支出则显示正贡献。
- 温饱、教育、医疗周变化只列当前生效的法案/发展档位、其他修正及缺口惩罚。
- 总消费品只列国营、私营生产各自贡献的成品数量。
- 分配率只列基础、私营建设、法案、政治点数带来的分配百分比及非零的边界修正，不显示建设产能或政治点数原值。
- 建设条只列直接基础产能、建设速度修正、法案扩张修正和缺口加成；倒闭时只列过剩造成的实际负进度，停建时隐藏未生效项目。
- 删除所有公式、单价、人数、工厂数量、每座产出、进度/成本等中间展示及计算说明。没有新增结算、贸易、工厂占用或生产逻辑。

38 个动态直接贡献条目使用正负分支和空文本回退，零值连同换行一起隐藏。小额货币/消费品按 M、K、原单位选择显示，避免非零量被两位小数截成 0.00；中间换算值不展示。面板打开和民工加减时，先更新预算、再缓存显示来源，调用次数与结算行为不变。
