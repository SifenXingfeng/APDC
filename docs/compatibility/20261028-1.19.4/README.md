# APDC：1.19.4 兼容检查与适配

本地安装版本为 **Operation Postern 1.19.4.0.48d6**，原版校验码 a783，Steam build 26132856；此前实际验收版本为 1.19.3。

依据为当前安装文件、项目实际覆盖关系、前次 1.19.3 运行日志，以及[Paradox 在 Steam 发布的 1.19.4 更新说明](https://store.steampowered.com/news/posts/?appids=394360&feed=steam_community_announcements)。本轮按项目实际覆盖项逐项适配。

## 核查范围与保留内容

- 启动器两个描述文件的 `supported_version="1.19.*"` 已覆盖 1.19.4，无需更改。外部描述文件指向的目录联接仍落到本主项目。
- 项目 38 条自定义 defines 在当前原版定义中均存在，无需改名。
- 按实际文件覆盖顺序检查 31 个本次更新的有效原版界面，新增引用中已无因项目图集覆盖而缺失的原版素材；素材检查以实际生效的图集为准。
- 国家身份、领导人、九类意识形态、州历史与核心、铁路、人口资源、经济后端、四个自定义面板、地图着色器、地图字体及美术素材保留。此前未提交的头像、投票界面和地图维护改动保留。
- 自定义装备参数、科技布局和学说具体加成沿用项目设定。1.19.4 的坦克可靠性与血量、导弹强度、学说奖励等平衡变化，不作为必须兼容的接口变更强行写入项目覆盖文件；未被项目覆盖的原版内容继续按新版本生效。
- 国家政治面板没有发现缺少新版同名控件。决议界面的差异为原版字号/位置等调整，没有本次必须补齐的功能控件，保留项目现状。建筑修理优先级、情报机构排队、原版国策小地图等界面由当前原版正常加载。

## 验证证据

`static-audit.json` 记录脚本解析、素材引用和项目自定义布局保护；`effective-graphics-audit.json` 记录实际覆盖后的 31 个原版更新界面依赖。

第一次针对性加载发现新增法国和会规则缺触发器，停止后修正；第二次发现三态图标定义被旧图集遮挡，停止后修正，并补充按有效覆盖关系检查素材。两次失败诊断日志分别保存到备份目录 `runtime-attempt1.zip`、`runtime-attempt2.zip`。这些诊断不作为最终通过证据。

最终 1.19.4 德国 2060 普通开局、日期推进、自动存档、经济每日推进与每周结算、全图政治关系，以及测试进程清理结果由 `runtime-audit.json` 记录。`runtime-state-math-review.png` 是第二次诊断运行中只读截取的实际冷战美国核心州详情；86 个核心州、103 个地图片块与前版一致，已查看，表明本轮新版状态变量类型修正未破坏该地图计算。后续修复只补充外交图标定义，未改变冷战地图或其脚本。

最终实际存档为 **Operation Postern v1.19.4.0.48d6 (b225)，2060.2.1.1**。b225 为启用 APDC 后的校验码；原版校验码仍为 a783。验证结果：31 次经济日推进、4 次经济周结算、全图 1,558 州关系一致，对比前次 1.19.3 没有新增独立错误消息。最终测试进程、日志辅助进程和 Steam 游戏运行标志已清理，用户设置与原自动存档哈希未变。

新原版按钮的鼠标交互没有逐项点验；本轮不把静态绑定检查或后台加载描述成全部新按钮已实际点击测试。测试使用私人桌面和隔离用户目录，不切换用户输入桌面，不发送鼠标/键盘输入；实际启用 APDC 及只读诊断驱动、全部原启用 DLC，未加载 Toolpack。

新运行日志与前次 1.19.3 日志按消息正文比较，原有音效、国旗、旧科技和贴图等告警分别记录，不将兼容通过表述为整个项目零告警。

## 备份与后续基线

原始涉及文件、此前日志和全项目 SHA-256 见主项目同级 `.codex_backups/APDC/20261028-125836-1194-compatibility`。`changes.json` 为本轮实际运行文件改动清单，`preservation-audit.json` 检查是否出现越界修改或删除。

`native-baseline.json` 保存当前原版 common/interface/FX 文本内容指纹和可执行文件指纹，便于下一次更新按内容精确比较；入口为 `tools/compatibility/baseline.json`。本轮涉及初始数据库和 UI 适配，验收使用新开局，不保证前版存档获得新增初始设定。
