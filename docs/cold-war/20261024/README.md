# APDC 冷战系统：实施与验证记录

本轮替换旧大博弈入口及其专属内容，保留现有经济、内阁、合作组织、地图政治历史与其他玩法。旧文件原始字节、哈希和输入素材位置见 `backup.json`；非目标文件保护结果见 `protection.json`。

## 运行结构

- 世界地图由当前 `map/provinces.bmp`、`definition.csv` 和州地块列表生成。固定轮廓不保存国家身份，实际拥有国在运行中读取。
- 本国红色、不可干涉灰色、可干涉蓝色、剧情标记为已控制的国家粉红色。拥有者变更触发地图版本更新，控制者临时改变不改国界。
- 国家详情仅选用当前拥有且为本国核心的州的轮廓，计算两种经度原点的边界框，选较紧凑的一种，等比居中。国家地图颜色与蓝白国界、州界分别绘制。非核心属地不参与轮廓与缩放；无核心领土时显示空图提示。打开的详情页每天只检查该国拥有州的核心标记，变化时重建，剧情也可调用 `apdc_cw_invalidate_maps` 立即刷新。
- 详情共用原尺寸距离场纹理，由固定比例的界面容器缩放。着色器根据比例恢复约定的屏幕描边宽度，避免逐缩放档位复制图片。
- 世界地图保留全部原生贴图、按钮尺寸、坐标和图层顺序，共用国家选择处理。国界显隐直接读取数组缓存，归属判断只在地图版本变化时计算；加载时准备玩家缓存，打开与返回时复用。详情图像键在 `common/synchronized_dynamic_tokens/APDC_cold_war.txt` 注册，直接索引，避免逐张匹配长本地化分支。不要将世界地图按钮改为运行后替换图片，或将地图层改为懒加载列表：后台对照分别发现边缘混合差异和打开面板时重建对象的停顿。
- 饼图保留全部 360 个扇区和原生鼠标区域，悬浮时绑定当前扇区索引，复用国家、变化和法案来源说明。份额显示缓存使用数组，不再为每条法案生成 360 份说明。
- 三项份额分别合计 100%，自主始终为来源索引 0。改变一方份额时，其他所有来源等比补齐。政治控制仅在低于经济与军事份额均值时上升；差距每 1 个百分点对应每日 0.01 个百分点，通常最低 0.01、最高 0.1，最后一步不超目标。
- 只每日结算已登记关系和法案，不每日遍历世界地图。地图、详情图和控制面板分别使用更新版本。
- 法案逐个“施行国—目标国”登记。执行与停止扣一次政治点；停止保留已形成的份额。相关国家不存在时停止持续效果。
- 国际地位为剧情值；当前附属关系覆盖显示为附属国，不覆盖保存的独立国际地位。

## 测试预设

所有国家开局三项均为 100% 自主。只有德国可干涉法国和低地联盟。德国有 28 条默认停止的测试法案：法国政治 8 条、经济和军事各 3 条；低地联盟政治 2 条、经济和军事各 3 条；德国自身每项 2 条。

法国政治页 8 行超过 256 像素列表区域，用于检查自动滚动条。德国本国每项包含提高自主和接受苏联影响的选项。没有自动设置国际阵营、附属关系或其他奖励；AI 策略暂不制作。

## 文件入口

- `tools/cold_war/laws.json`：法案定义、名称、效果和测试解锁设置。
- `tools/cold_war/build.py`：重新生成脚本、界面、本地化；只有地图或地图素材改变时才加 `--map`。
- `tools/cold_war/qa.py`：建立独立用户目录与验证驱动。
- `common/scripted_effects/APDC_cold_war*.txt`：控制、剧情接口、法案和显示缓存。
- `common/scripted_guis/APDC_cold_war.txt`、`interface/APDC_cold_war*`：界面及交互。
- `gfx/FX/apdc_cw_palette.shader`：冷战详情图专用，未修改游戏大地图着色器。

地图生成工具使用 NumPy、Pillow 与 SciPy 1.15.3；本机额外工具依赖安装于 `D:/APDC_ColdWarTools/pydeps`。正常运行模组不需要 Python 或 SciPy。

## 剧情接口

国家参数使用国家变量保存，不能用全局事件目标充当玩家当前选择。每个玩家各自保存选择与显示缓存。

### 设置干涉权限和已控制状态

在干涉国作用域执行，`apdc_cw_value` 为 1 添加、0 取消；两种状态独立。

```text
GER = {
    set_variable = { apdc_cw_target = FRA }
    set_variable = { apdc_cw_value = 1 }
    apdc_cw_set_intervention = yes
    apdc_cw_set_controlled = yes
}
```

### 改变控制份额

在被影响国家作用域执行。轴 1/2/3 为政治/经济/军事；delta 单位为百分点，可以为负。

```text
FRA = {
    set_variable = { apdc_cw_actor = GER }
    set_variable = { apdc_cw_axis = 2 }
    set_variable = { apdc_cw_delta = 5 }
    apdc_cw_change_control = yes
}
```

提高自主时 actor 使用当前被影响国；其他国家也按原比例缩减。更改不自动建立剧情上的“已控制”状态。

### 设置国际地位

```text
FRA = {
    set_variable = { apdc_cw_value = 5 }
    apdc_cw_set_status = yes
}
```

值为 1 未获承认、2 附属国、3 弱国、4 小国、5 地区性大国、6 国际性大国。原版附属关系在显示时优先。

### 解锁、锁定和移除法案

新增法案先在 `laws.json` 定义，然后运行生成器。`initially_unlocked` 默认不设置；测试预设为 true。生成的 `apdc_cw_unlock_law_<ID>` 在 owner 作用域调用，初次解锁为停止，重复调用不会重置执行状态。

锁定或移除现有记录：

```text
GER = {
    set_variable = { apdc_cw_target = FRA }
    set_variable = { apdc_cw_id = 1 }
    set_variable = { apdc_cw_value = 1 }
    apdc_cw_lock_law = yes
    # 解锁：value = 0 后调用相同接口。
    # 停止并从列表移除：apdc_cw_remove_law = yes
}
```

锁定只改变可选性；移除会停止持续作用。两者都不撤销历史控制份额。

## 验证证据

本文件记录实现结构，不替代运行与视觉证据。最终检查、测试日志、测试进程清理和仍未验证的项目另行记录。界面解析、逻辑检查通过不等于实际鼠标判定或显示已通过。

## 原生脚本兼容注意

冷战系统的变量、数组与自定义循环计数器统一用小写。原生循环参数与部分变量索引路径对大小写的处理不同；后台对照已确认混用会让计数器读取为 0。脚本数值最多输出五位小数；六位小数字面值的对照比较未按预期解析，缩放与数值检查统一规避。

详情图的像素居中通过各轮廓的本地坐标实现，缩放容器仅保留固定比例，不依赖脚本修改容器位置。

## UI 输入修复（2026-10-24 后续）

前次 72 项后台效果检查不覆盖真实鼠标命中，不能作为按钮可点的证据。原透明按钮共用 1×1 纹理；原生输入范围取纹理尺寸，按钮的 size 不能替代真实点击贴图尺寸。现采用经济与合作组织界面已有的做法：标签直接使用 171×59 的标签材质，执行/停止使用 92×30 的透明 TGA 热区，关闭和图例也改为对应尺寸。`tools/cold_war/check_ui.py` 检查实际素材尺寸、层级、绑定及饼图内部遮罩，避免再出现该问题。

饼图已移除内部挖空；当前标签采用合作组织的“普通标签在页面下、当前标签副本在页面上、标题在副本上”的绘制次序。每条法案只显示一行切换费用，执行和停止每次切换都扣同一金额。JSON 统一使用 cost；为兼容已有存档，运行数组沿用 execute_cost 的旧名称，但该数组现在是双向切换共用的唯一费用，旧 stop_cost 不再参与。

本次 74 项后台检查通过，冷战新增运行报错为 0；原有 705 条外部记录未变。游戏内截图确认实心饼图、当前标签置顶和一行费用。详细证据在 `ui-fixes/final.json`、`ui-fixes/ui-audit.json` 和 `ui-fixes/native-ui-fixed.png`。仍未进行真实鼠标/键盘操作，不将静态热区和后台效果检查称为人工点击验收。测试游戏与两个辅助进程已关闭。


## 初次显示回归修复（2026-10-25）

地图数据缓存有效不等于隐藏界面的绑定已经刷新。打开、重新打开、从详情返回及加载时调用 `apdc_cw_bind_world_ui` 强制推进 GUI 更新版本；有效数据缓存仍复用。缓存构建计数与 GUI 更新计数分别记录，测试不能再用 GUI 版本不变来代表缓存复用。

验收必须先在无领土/控制改动的正常开局完成首次打开、关闭重开、详情和返回的原生截图，再执行会改变数据的集成测试。否则数据变动会掩盖显示初始化缺失。详见 `../20261025-map-display-regression/README.md`。
