# 冷战界面启动优化（2026-10-25）

用户选择保留面板打开较快的方案。当前 `tools/cold_war/render_mode.json` 为 `native`；正式运行文件与通过 86 项检查的原生部件版一致。快速列表版没有接入正式运行文件。

## 保留的修改

- 保留世界地图全部原生贴图、按钮尺寸、坐标、图层与原生按钮状态；国界显隐改读缓存，归属判断在地图版本变化时计算。
- 加载时准备玩家缓存，打开和返回时只在缓存过期后刷新；选择国家共用处理，领土与干涉权限变化仍立即使缓存失效。
- 饼图说明从 12,242 个重复定义合并为 752 个定义，保留 360 个完整扇区、颜色、图例、数值与来源；原生日志验证重复悬浮不同国家不会串索引。
- 详情地图使用注册图像键直接索引，保留全部 26 个缩放档位、472 个调色颜色以及原始距离场贴图。
- 删除未使用的进度状态，解码倍率同步调整；12,272 个有效编码逐一对照无差异。

## 实测与边界

同配置 GER 2060、全部启用 DLC 与 Toolpack、1920×1080、独立后台用户目录：

| 场景 | 界面资源初始化 | 启动至图形就绪 | 首两次每日日志间隔 |
|---|---:|---:|---:|
| 修改前首次对照 | 69 秒 | 158 秒 | 3 秒 |
| 保留的原生部件版 | 61 秒 | 138 秒 | 2 秒 |
| 未选用的快速列表试验 | 13 秒 | 90 秒 | 19 秒 |

每日日志间隔包含常规模拟计算，不等同于精确鼠标点击延迟。原生布局仍承担大量控件的启动准备，缓存方案不声称完全消除该阶段的等待，也不声称显著降低总内存峰值。中间几轮更快的列表方案因边缘差异或首次显示等待没有选用；后来显式保留按钮状态帧的快速版已达到像素一致，但仍有首次显示约 19 秒的准备，用户选择不采用。
