# 整国反馈尝试与按用户要求回退

未获得可靠的整国悬浮/按下联动实现。当前版本的隔离测试拒绝 multiSpriteButtonType 等候选控件；同一容器内多个背景可显示，但未验证其具有所需的联合 Alpha 点击区域及共享交互状态。对私有测试窗口发送的后台消息未能建立可靠悬浮对照，不能据此声称容器原理已被排除，也不能声称整国联动已完成。所有原型仅位于隔离测试档，未写入主项目。

用户要求不再强求并回退：已移除主项目 1700 个单州反馈覆盖按钮、对应转发回调、额外 Sprite 定义以及未再使用的专用世界地图反馈着色器。原世界地图按钮保留点击和国家名称悬浮窗，使用原生 buttonstate_onlydisable.shader，其 Up/Over/Down 都使用 PixelShaderUp，不再执行提亮或变暗逻辑，Disable 保留原有渲染。地图图形、州易主更新、颜色及国境保持既有实现。

返回按钮第一帧、法案按钮的反馈、三个面板背景不变暗及指定说明悬浮窗删除等其他修改保留。生成器同步处理，重建哈希一致。原有冷战 scripted GUI 已与增加单州反馈前逐字节一致；界面输入范围及 5311 地图部件几何检查通过。三个隔离测试的游戏与辅助进程均已关闭，Steam 运行标记已清理。回退仅做静态验收，没有再启动主项目游戏。
