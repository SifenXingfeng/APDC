## 性能修改

- 地区系统每日全图遍历从每个国家各执行一次改为全世界每日一次。原入口实测每天触发 156 次；更新计数断言确认地区与经济全图更新每天各执行一次。
- 多人情况下地区周更新也只做一次；内阁日刷新、经济体制与部队月初始化的全图遍历增加全局周期保护，保留第一次调用的顺序。
- 删除临时的每日全州工厂诊断日志。
- 费用预算在每周实际结算、面板显示和玩家操作时刷新，关闭面板的 AI 无需每日遍历所有科技/专项来估算预算。预算公式和每周扣款、发展度结算函数与优化前逐字一致。
- 计划经济已经采用计划分配时，不再每日重复移除/添加同一法案。
- 没有有效私营军工产能时跳过逐装备生产；面板只计算已解锁装备的库存与进度显示。
- 消费品交易先收集进口需求国，再按原顺序匹配卖家。关税、禁运、交战排除、供给排序及等额分配规则保留。
- 仍保留每日装备解锁检查，避免外部工具直接改科技时漏更新；没有使用不能保证兼容的科技数量缓存。
