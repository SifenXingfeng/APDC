# 核心州被错误纳入占领抵抗流程：误删审计与修复

## 原因与责任

此前清理旧内容时，只沿脚本文本调用关系保留依赖，漏掉了由引擎直接调用的入口。新增空文件覆盖本体 `00_resistance_initiate_triggers.txt` 后，`should_initiate_resistance` 整体消失，包括本国核心不启用抵抗的条件。缺失入口没有产生加载错误，所以此前零项目错误日志和经济断言未能发现此回归。此项误删应由本轮实现承担，不能归因于地图或用户存档。

用户的 2060.3.1.2 自动存档中仍有 179 份国家核心列表、1764 条州核心关系。二进制列表的州 ID 集合与当前历史中的各国家核心列表多重集完全一致；GER 的 22 个核心包含柏林州 64。此检查没有把每份二进制列表都解码绑定到国家 tag，具体方法和限制记录在 `static-audit.json`。1558 份州历史逐字节匹配清理报错前备份。

先前隔离经济测试存档中，1557 个州启用了抵抗，其中 1488 个州仍是所有者的核心。这是此前运行验收遗漏的实际功能错误。

## 那批清理的确切规模

- 1497 个变动路径：39 个实际删除文件、454 个已有文件修改、1004 个新增覆盖文件／素材／工具路径。新增路径并不等于新增玩法。
- 实际删除的 39 个文件包括 37 份未注册的旧原版国家历史、1 份旧完整 defines、1 份重复党名本地化。没有删除州历史。
- 160 份脚本库共移除 3065 项定义：16 份效果库、33 份触发器库、96 份理念文件、9 份动态修正文件、2 份权力平衡文件、4 份国家领袖特质文件。此数是最初移除数量，包含本次补回的定义。
- 全部文件名与定义名见 `deletion-inventory.json`；摘要和范围限制见 `audit-summary.json`。

以上是改动数量，不表示这些删除全部有问题，也不表示其余改动已获得完整玩法验收。

## 已修复的同类问题

恢复 25 个引擎入口和 1 个必需依赖：抵抗判定 1 个、情报 AI 判定 2 个、外交有效性入口 2 个、外交通用限制入口 20 个，以及盟国参战条件的辅助触发器。恢复内容来自当前本体或清理前 APDC 的通用规则；未恢复原版二战剧情的国家／国策特殊限制。

对 3065 项移除定义，复查可执行文件中的完整名称和原版文档说明的动态外交入口命名族，得到 32 个候选。25 个必要入口已恢复；5 个仅包含旧国家条约或保护国限制的外交入口仍不恢复；`lerp` 是无调用的瑞典算术工具，`ai_test_startup_effect` 属于本体专用 AI 测试场景。全部判定见 `engine-callback-candidates.json`。随后补齐被恢复入口的脚本依赖。

`tools/performance/engine_callbacks.py` 检查 25 个有效入口、1 个依赖及核心排除条件，已接入现有静态验证器。不能再把“项目脚本中找不到调用”单独当作可删除依据。此次审计覆盖以上入口与依赖，不构成对全部 1497 个改动路径的穷尽玩法测试。

使用用户自动存档的副本，从 2060.3.1.2 通过 `-continuelastsave` 在独立用户目录、私有桌面后台加载。原存档、启动器配置和用户设置均不写入。本轮没有用脚本补核心、转移州、关闭全局抵抗或重放初始政治关系。
