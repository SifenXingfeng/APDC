# 消费品贸易与经济统计优化（2026-10-23）

> 回归验收更正：此报告的 57 项经济断言遗漏了更早报错清理引入的核心州抵抗异常。用户发现后确认，核心关系仍在，但必要的引擎抵抗判定入口被清空。相关基础规则已补回，并用用户旧档副本单独验证恢复；原来的零项目错误结论不能代表完整玩法无回归。详见 `../20261023-core-regression/README.md`。

已按确认范围实施，原版战略资源贸易和国际装备市场未改动。

## 运行方式

- 消费品贸易每周发起一轮撮合。按关税升序、同关税出口量降序生成卖家名单，每日最多处理卖家总数的七分之一向上取整，七次日更新内完成。
- 准备下一轮安排期间继续执行当前安排。新安排完成后切换整份数据，避免单方面更新进口或出口。开局只在加载阶段完整准备第一轮安排。
- 每日只核对已有关系：交战、禁运、国家消失或供需容量降低时，对双方同步缩减或停止贸易；每日核对不会寻找新伙伴或恢复已经缩减的数量。
- 消费品仍是持续供给，进口先进入分配前的池子，不储存、不乘以七。双方关税分别按自己的税率计算，每周结算国库。
- 私营军工目录在相关科技解锁后标记更新，在下一次生产或界面读取前刷新；每个国家还会每周校验一次，按七组分散执行。手动授予科技等没有触发回调的情况由例行校验补齐。
- 建设、拆除和装备生产继续每天推进。装备生产只遍历当前生产的型号，旧型号退出生产后保留库存及生产余量。

## 其他复用与兼容

- 人口、私营工厂及有效工厂产能仍每天完整统计，界面操作复用当日结果。落成、拆除和州控制权变化会使缓存失效。
- 科研与专项活动计数在同日复用；打开面板和每周实际扣款前重新读取。费用公式未改。
- 已完成的计划经济国有化不再每天重扫所有州及库存；发生相关变化时处理，并保留每周校验。
- 去除没有消费者的每日修正值复制。面板数据数组不再反复清空重建，界面在数据或输入变化后刷新。
- 保留原有195个装备编号，160款有效装备沿用原编号，其余编号继续预留。旧库存和生产进度一次性迁移到数组，后续刷新不重置；数组扩展也保留已有数据。
- 128项相关科技增加目录更新回调；原回调及其条件完整保留。正常重建不再自动执行旧内容迁移步骤。
