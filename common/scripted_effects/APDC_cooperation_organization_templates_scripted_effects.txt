# Cooperation-organization templates
#
# A template is an author-facing creation effect run in the anchor country's
# scope during country-history setup or an event. Keep all opening membership
# and chair declarations in the template. Every created container receives the
# shared placeholder legislation automatically.
#
# To add a template:
# 1. Copy one complete effect below and choose unique definition/name/icon ids.
# 2. Register the name id in APDCCooperationOrganizationName.
# 3. Register the icon id in APDCCooperationOrganizationIcon and its GFX sprite.
# 4. List every opening member explicitly and set one joined member as chair.
# 5. Optional organization-specific law groups are registered on this same
#    anchor after APDC_create_cooperation_organization. Set the four temporary
#    definition fields documented in APDC_cooperation_legislation_scripted_effects.txt
#    and call APDC_add_cooperation_law_group_to_container = yes.
# Runtime additions/removals then use the generic API and do not modify this file.
