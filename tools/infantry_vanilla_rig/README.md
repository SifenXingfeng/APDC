# 通用步兵：接回原版骨架

2026-09-16 修订。保留现有通用步兵的身体、原版来源脸部、头盔、面罩、迷彩与 AK-12 外观；不修改其他人形、UMP、涅托和马达加斯加企鹅。

## 实际变更

- 骨架使用本机原版 `GER_infantry.mesh` 的 33 个骨骼及挂点，名称、顺序、父子关系、原始逆绑定矩阵逐项一致。没有修改原版文件。
- 把原有简化姿态的身体重新适配到原版休止姿态，重新分配蒙皮；处理腕部扭转、髋部接缝和衣领。
- 原版来源脸部恢复原始脸部/颈部蒙皮权重，保持脸部几何比例；移除与原脸颈部重叠的第二段程序生成肉色圆柱。没有拉长脖子、重建眼睛或抬高头部。
- AK-12 从人物网格拆出，作为独立武器挂在原版四个武器节点上，随原版动画换手、背枪、落枪；弹匣方向沿用此前修正版。
- `APDC_r6_infantry_entity` 采用原版步枪步兵完整状态机，覆盖人物网格和四个武器附件；为避免跨文件父实体尚未登记，状态配置直接展开写入，不依赖加载顺序。原版状态转换、动作、脚步及射击事件继续使用。射击粒子挂点移到 AK-12 枪口。
- 人物网格登记直接引用 27 个原版动画，不再使用旧包的三个自制基础动作。包括移动、行军、撤退、站射、蹲射、冲锋、死亡、长待机、训练及原版骑乘映射。
- 模型内部采用原版骨架尺寸，实体整体缩放抵消内部尺寸变化，保持此前地图模型的站立高度。

## 验证与重建

依次用 Blender 后台执行 `build.py`、`verify.py`，然后用普通 Python 执行 `install.py`。Blender 调用应加 `--python-exit-code 1`；`verify.py -- --quick` 只适合姿态预览，不替代最终完整检查。

完整检查对 27 个原版动画各抽取 5 个时刻，检查有限坐标与异常拉伸；另外检查待机、移动、站射、蹲射、死亡、训练的渲染预览。该检查不等于逐帧人工审定，也不等于游戏内最终光照和性能验收。

本次仅是外观、骨架与动画资源更新，不改单位参数、装备、解锁和编制。需要完全重启游戏以重新加载资源；不要求因此重开存档。
