# 人物动作、Q 版骑乘组合与载具材质修订

仅修改外观资源，不改变营种、装备、单位参数或用户存档。原版游戏文件只读。

## 本次范围

- 战术人形：原版德国步兵 33 骨骼与原始绑定数据；身体重新适配，AK-12 拆为原版四挂点武器，移除抽烟状态及香烟附件。
- 柳芭：同一套原版 33 骨骼，另加两根轮椅轮骨；从原版动作提取上半身，冻结根、髋和腿，下身及轮椅框架蒙皮到静止根骨，移动时只转车轮。不是让整个人播放站立走路动作。
- UMP 骑兵：重做 Q 版上下骑乘组合，替换原并排两人实体；旧 UMP45/UMP9 不再注册为可选实体。包含眨眼、头发摆动、观察、调整姿势、奔跑、点射后坐及倒下。
- 涅托、基础自动化机械、多足机械及火炮变体、末日魔犬、AA02：三种待机、移动、攻击和死亡六组状态，膝盖求解使用固定弯曲平面，避免接近伸直时翻面。射击型单位增加枪口粒子与声音；涅托采用近战挥镰。
- 歌莉娅、通用直升机和武装直升机：悬浮、悬空移动、俯仰和相应攻击/坠落动作；直升机持续旋翼运动，不再使用贴地步态。
- 载具：28 张颜色贴图恢复被多余 sRGB 解码压暗的亮度。只进行确定性的色彩空间纠正，不改法线、金属度和光泽数据贴图。

## 验证和文件

`art_source/unit_motion_refresh/source/` 保存可编辑模型；`previews/` 是模型文件回读后的离线渲染，非游戏截图。

`verify.py` 回读最终 `.mesh`、`.anim`、DDS，检查全部移动帧的有限坐标、蒙皮、膝盖弯曲平面、飞行净空和柳芭静止下身；其余状态抽样检查。最终光照、动画切换观感仍需游戏画面验收，不能只凭日志宣称完美。

安装使用独立备份清单，保留安装前文件；旧桌面模型包不覆盖。批量单位生成器会保留本次已验证的修订，不回写旧包覆盖新动作。

2026-09-17：12 套模型通过二进制回读；66 个自制动画文件和原版动画映射通过检查；安装 124 个资源文件后，隔离启动游戏的本次相关资源错误为 0。游戏最终光照、状态切换及观感没有逐项人工验收，仍以明确的验证范围为准。需要完全重启游戏加载模型更新，不要求为这些外观修改重开存档。

重建顺序：普通 Python `materials.py`；Blender 后台 `animate_existing.py`、`rebind.py`、`build_ump_chibi.py`；普通 Python `finalize.py`；Blender `ground_death.py`、`verify.py`、`tidy_sources.py`；普通 Python `check.py`、`install.py`。Blender 使用 `--python-exit-code 1`。这些脚本依赖清单中已记录的本机原始素材与导出器路径。
